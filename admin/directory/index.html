Где используется

Отметьте опубликованные события мастера, с которыми нужно связать эту карточку. Старые страницы и карточки CRM автоматически не связываются.

Для каждой даты выбирается одна общая площадка и до пяти участников. Название и адрес в билетах и заказах остаются прежними.

Существующие страницы

Свяжите сохранённую карточку со старой страницей вручную. Выберите только те поля, которые должны обновляться вместе с карточкой. Адрес и остальные материалы страницы сохраняются.

Пустое поле означает, что оно не связано. Для отсоединения страницы снимите все выбранные поля. При отсоединении опубликованный текст останется на странице.
